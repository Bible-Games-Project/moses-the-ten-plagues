# Moses: The Ten Plagues

Moses: The Ten Plagues

Create a complete browser game inspired by the gameplay philosophy of Level Devil, but with an original biblical setting, original assets and original level design.

General Style

2D side-scrolling platformer.

Pixel art.

Extremely minimalist visuals.

Very simple animations.

Smooth controls.

Instant respawn after death.

The entire game should feel polished despite its simplicity.

Story

The player controls Moses.

His mission is to free the Israelites from Egypt.

The game contains 11 levels:

Water Turned to Blood

Frogs

Gnats

Flies

Livestock Disease

Boils

Hail

Locusts

Darkness

Death of the Firstborn

The Escape from Egypt

Each level represents one plague and introduces mechanics inspired by that plague.

LEVEL 1 ONLY

For now, build ONLY the first level.

Title:

Plague I – Water Turned to Blood

Visual Style

Everything is monochromatic.

Main color:

Dark crimson / blood red.

Only use different brightness values of the same color.

No gradients.

No textures.

Very clean pixel art.

Background should include:

simple pixel pyramids

a few palm trees

a river

a large sun

Everything should remain minimalist.

Player

Moses is represented as a tiny pixel character.

He has:

walking

jumping

Nothing else.

Controls

Arrow keys or A/D

Space to jump.

Objective

Reach the exit door on the far right.

The level should take around 30–60 seconds to complete after learning its tricks.

Gameplay Philosophy

The game should surprise the player.

The environment itself is the enemy.

The level should contain unexpected events that activate when the player approaches them.

Examples:

platforms disappear

spikes emerge

bridges collapse

walls move

safe areas become dangerous

dangerous areas become safe

These surprises must always feel fair and funny.

Never impossible.

Plague Theme

Every surprise must relate to the first plague.

Ideas:

the river suddenly rises

blood floods part of the level

platforms sink into the blood

blood fountains appear

floating platforms drift away

blood currents push the player

Avoid random traps that have nothing to do with the plague.

Death

When Moses dies:

instant respawn

no loading screen

keep gameplay fast

Ending

At the end of the level:

Moses reaches Pharaoh.

Pharaoh simply says:

"No."

Fade to black.

Display:

"The first plague was not enough."

Then show:

"To be continued..."

Do not build the next level yet.

Audio

Minimal retro sound effects.

Small jump sound.

Retro death sound.

Soft ambient Egyptian atmosphere.

Technical Requirements

Responsive browser game.

Keyboard support.

Pixel-perfect rendering.

Smooth camera follow.

Stable 60 FPS.

Clean and modular code.

The game should feel like a polished indie pixel platformer inspired by classic precision platformers, while remaining completely original in its art, level design, mechanics and biblical theme.
